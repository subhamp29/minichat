# Remote Router Backend

The remote router backend has been removed from MiniChat. All router-related environment variables (`ROUTER_BASE_URL`, `ROUTER_API_KEY`, `ROUTER_MODELS`, `ROUTER_TIMEOUT`) and code paths have been deleted.

Use the built-in **Groq + Gemini Fallback (Cloud)** or **Qwen2.5 0.5B (Q4_K_M) - Ultra Fast** models instead.
